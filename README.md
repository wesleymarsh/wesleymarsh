## Dungeon Forge
A grid-based procedural dungeon generator for Unreal Engine 5.4.4, designed to be modular and easy for developers with no C++ experience to use through Blueprints.

Initially prototyped in 6 weeks, and will be open sourced after a refactor to improve performance and make the plugin more intuitive to use.
